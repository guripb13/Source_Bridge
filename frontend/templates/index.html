A few helpful tips

  • Start with your code. Paste it into the source editor or upload a text-based code file.
  • Choose your languages. Pick a source and a target from Python, Java, C and C++. Use Change languages in the workspace to switch at any time.
  • Keep writing. Enter creates a new line. Ctrl + Enter (⌘ + Enter on Mac) starts a translation.
  • Take it with you. Copy, download, or bookmark a finished translation. Hold Alt and drag code into another app.
  • Keep a history. Create an account or sign in and every translation, finished or not, is recorded under History. Bookmarked ones also live in Saved.
  • Review the result. Check and test translated code before using it in your project.
